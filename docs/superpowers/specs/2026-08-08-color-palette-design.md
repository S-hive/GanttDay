# 任务基础色板

- 状态：已确认（浏览器试调后聊天确认；未收到自定义 payload，采用草案默认 hue）
- 日期：2026-08-08
- 范围：标签色、任务 `autoHue` / 覆盖色选色 UI；不改紧迫度插值、不改壳层 Theme

## 1. 目标

用**少量预设色**表达简洁、鲜明、克制；默认不再从 0–359 任意随机。需要时仍可展开自定义色相滑条。

## 2. 色板

用户指定的柔和底色（7 色；灰为中性）：

| id | 名称 | hex | 存储 hue（约） |
| --- | --- | --- | --- |
| peach | 桃 | `#FFDAC1` | 24 |
| leaf | 芽绿 | `#E2F0CB` | 83 |
| mint | 薄荷 | `#B5EAD7` | 158 |
| lavender | 淡紫 | `#DDD6FE` | 251 |
| sky | 天空 | `#bae6fd` | 201 |
| cream | 奶油 | `#FEF3C7` | 48 |
| gray | 灰 | `#dee2e6` | 211 |

存储仍为整数 `hue`（兼容现有 DB / 备份）。色点/冷静态预览用精确 hex；紧迫度从该色的 S/L 线性加深到 S=1.0、L=0.45。

## 3. 任务创建时的颜色

1. **基础色**：创建任务条时，`autoHue` 从色板 8 色中**随机**取一格并写入（有主标签则仍跟主标签 hue；无主标签用 `autoHue`）。
2. **紧迫度加深**：绘制时 `UrgencyPalette` 在该基础色相上按距计划结束时间提高饱和度、降低明度；逾期封顶 + 斜纹。

## 4. 选色 UI

- 新建标签 / 任务覆盖色：主交互为 **8 色点**；标签默认建议用「距已有最远」的色板项（`farthestPaletteHue`），便于区分分类。
- 「自定义…」展开后显示 0–359 色相滑条。
- 当前 hue 不在色板时：色板无选中，滑条显示该值（兼容旧数据）。

## 5. `pickAutoHue`

- 仅用于任务创建：`kTaskColorPalette[random]`，不再从 0–359 全色环随机。

## 6. 非目标

- 不强制迁移已有任务/标签 hue
- 不做深色主题壳层
- 本轮不改紧迫度曲线形状（仍用现有线性加深）
