# 月视图跨日色条

- 状态：已实现
- 日期：2026-08-08
- 范围：`MonthPage` 及月视图布局/排程辅助逻辑

## 1. 问题

当前月视图在每日格子内**逐行罗列最多 3 个任务标题**，超出显示 `+N`。跨日任务被拆成多天重复标题，无法一眼看出日期跨度与日内起止。

## 2. 目标

改为类似日历「事件条」的呈现：

- 彩色横条**横跨任务所覆盖的日期范围**
- 条上**只显示任务名**
- 每个自然日最多展示 **10** 条；超出用 `+N`
- 每个日格表示 **当日 0:00 → 次日 0:00**；条的左右边界在首尾日格内按时刻近似 inset
- 条高约 **14–16px**，保证任务名可读

## 3. 布局（方案 A）

1. 月网格按**周行**组织（周一～周日，与现有表头一致）。
2. 每周一行：上方为 7 个日期数字格；下方（或叠在格内）为任务条层。
3. 同一周内，任务若覆盖多日，画成**一条连续横条**。
4. 任务跨周时：在每一周各画一段（同一任务尽量使用相近 lane）。
5. 周内对重叠任务做 **lane 分配**（互不垂直重叠）；竖向间距约 2px。

## 4. 日内时间映射

对可见于某日格 `D`（`[dayStart, dayStart+1day)`）的任务片段：

| 情况 | 左边界 | 右边界 |
| --- | --- | --- |
| 任务开始日 | `cellLeft + cellWidth * (startOfDayFraction)` | 铺到格右（若当日未结束）或结束 fraction |
| 中间日 | 格左 | 格右 |
| 任务结束日 | 格左（若非同日开始） | `cellLeft + cellWidth * (endOfDayFraction)` |
| 单日任务 | start fraction | end fraction |

其中 fraction = 当日已过分钟 / 1440，夹在 `[0, 1]`。极短任务给最小可见宽度（例如 4px），避免看不见。

## 5. 上限与 `+N`

- 以**自然日**计数：某日重叠到的可见条数上限为 10。
- 排程时优先保留开始较早 / 跨度较长的任务（实现可选稳定排序：`plannedStart` 升序，再 `plannedEnd` 降序）。
- 某日被挤掉的条数合计为 `N`，在该日日期区附近显示 `+N`。
- 点击 `+N` 或日格空白 → 进入该日日视图（沿用 `onOpenDay`）。

## 6. 视觉

- 填充色：与日/周视图相同的 urgency / hue 规则（`TaskPaint` → `colorOf`）。
- 圆角约 4–6px；文字白色/对比色、单行、左对齐、省略号裁切。
- 已完成任务可沿用日视图的弱化/斜线语义（若成本低）；否则至少降低饱和度。
- 今天：日期数字高亮（可保留现有主色提示）；不强制改变条样式。

## 7. 交互

- 点击日格空白 / `+N` → `onOpenDay(day)`。
- 点击色条 → `onOpenDay(该条在当周可见的起始日)`（本版不直接打开任务编辑页）。

## 8. 非目标

- 不在月视图内拖拽改期
- 不显示时间文字、备注
- 不改周视图
- 不做农历 / 节气（参考图中的农历不在范围）

## 10. 验收

- 跨多日任务在一周内是连续色条，标题只出现一次（该周段上）
- 单日任务条左右位置反映大致开始/结束时刻
- 某日超过 10 条时出现 `+N`，前 10 条仍为色条
- 点击日格进入日视图
