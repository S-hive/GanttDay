# 设置页色卡：内联取色器

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：设置抽屉「色卡」区块的新建/改色交互；不改色卡数据模型、删除/设默认、紧迫度、标签绑定

## 1. 目标

点击色卡或「+ 新建」时，**不弹窗**；在色卡圆点行**正下方**展开取色器（SV + 色相 + HEX），确认后写库并收起。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 呈现方式 | 抽屉内联面板（色卡行下方） |
| 新建 | 与改色同一套内联面板 |
| 同时展开 | 至多一块 |
| 取消 | 不保存并收起 |
| 弹窗取色 | 设置页色卡路径不再调用 `showArgbColorPicker` |
| 他处 `ArgbColorField` | 本轮不改（仍可弹窗） |

## 3. 交互

| 操作 | 行为 |
| --- | --- |
| 点色卡 | 展开内联取色器，初始色 = 该卡 `argb`；该卡显示编辑中描边 |
| 点「+ 新建」 | 展开同一面板，初始色 = 当前默认色卡（无则既有兜底色）；无「编辑中」圆点，或对「新建」按钮做轻量选中态（实现时二选一，优先简单） |
| 点另一张色卡 | 切换编辑目标与初始色（未确定的草稿丢弃） |
| 确定 | 新建 → upsert 新卡；编辑 → 写回该 id；然后收起 |
| 取消 | 不写库，收起 |
| 再点正在编辑的同一张色卡 | 等同取消（收起、不保存） |
| 长按色卡 | 不变：设为默认 / 删除 |

面板内容与现有 `_ColorPickerDialog` 一致：SV 方块、色相滑条、HEX（非法 hex 不写入）、取消 / 确定。

布局顺序：色卡标题行 → 色卡 `Wrap` → **（可选）内联取色器** → 标签区块…

## 4. 实现要点（约束，非逐步计划）

- 从 `argb_color_field.dart` **抽出可复用的内联取色器控件**（状态：HSV + HEX 联动），对话框版可薄包装该控件，避免两套逻辑。
- `SettingsPage` 用本地状态记录编辑模式：`null`（收起）/ 编辑某 `ColorSwatch` / 新建。
- `_showSwatchDialog` 改为打开/切换上述状态，不再 `showDialog` 取色。

## 5. 非目标

- 色卡改名、拖拽排序、删除确认流程
- 任务表单等其他页面的选色 UI
- 动画规格（可用简单 `AnimatedSize` / 直接显隐；不强制）

## 6. 验收

- 设置抽屉内改色 / 新建不出现取色 `AlertDialog`
- 取色器出现在色卡行下方、标签上方
- 确定后列表颜色更新且面板收起；取消后颜色不变且面板收起
