# 标签筛选收入 AppBar 菜单

- 状态：已确认（聊天设计评审；含月视图筛选补充）
- 日期：2026-08-10
- 范围：日/周顶栏常驻 FilterChip 行 → AppBar 设置左侧筛选图标 + 浮层多选；有筛选时图标角标；**日/周/月三视图均消费同一套 `filterTagIds`**；不持久化筛选项、不改设置页标签管理

## 1. 目标

腾出日/周时间轴纵向空间：标签筛选不再常驻一行，改为 AppBar 入口；需要时再打开。筛选能力覆盖日、周、月，语义与现网日视图一致。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 入口位置 | AppBar `actions`，设置图标**左侧** |
| 打开方式 | 点击图标 → 浮层（`MenuAnchor` 或等价） |
| 浮层内容 | 「全部」+ 各标签，多选 FilterChip（含色点），逻辑同现网 |
| 关闭 | 点浮层外 / 遮罩即关；选择即时生效，无「确定」 |
| 激活提示 | `_filterTagIds` 非空时图标右上角小圆点（主题色） |
| 无标签 | 不显示筛选图标（对齐现网「无标签不显示筛选条」） |
| 作用视图 | **日、周、月**共用 shell 里的 `_filterTagIds` |
| 匹配规则 | 与日视图相同：主标签 **或** 任务附加标签任一命中即保留；空集合 = 全部 |
| 持久化 | 不持久化；进程内状态，重启默认「全部」 |

## 3. 交互

1. 去掉 `body` 顶部日/周常驻 `FilterChip` 行。
2. 有标签时，设置左侧显示筛选图标（建议 `Icons.filter_list`）；三个导航 tab 下均可见。
3. 点击打开浮层：内容与现网 chips 等价（「全部」清空集合；点选标签增删 id）。
4. 筛选非空 → 图标角标小圆点；回到「全部」→ 角标消失。
5. 日/周/月均传入 `filterTagIds`；切换 tab 不重置筛选。

## 4. 实现落点

- `lib/ui/shell/app_shell.dart`：移除顶栏 chips；`actions` 增加带角标的筛选入口；`MonthPage` 传入 `filterTagIds`。
- `lib/ui/month/month_page.dart`：新增 `filterTagIds`；在 `selectVisibleMonthTasks` 之前按日视图规则过滤 `_tasks`（`didUpdateWidget` 在筛选变化时重建即可，无需重订 stream）。
- 日/周现有 `filterTagIds` 传参保留；**若周视图当前仅按 `primaryTagId` 过滤，本轮一并改为与日/月相同的「主标签 ∪ 附加标签」规则**，避免同一次筛选在不同 tab 结果不一致。

## 5. 非目标

- 设置页标签 CRUD
- 筛选项跨启动持久化
- 自定义 Overlay 动画/复杂定位
- 月视图 overflow「+N」语义之外的新布局规则（过滤后按现有 layout 重算即可）

## 6. 验收

- 日/周默认无顶栏筛选行，时间轴多出一行高度。
- 设置左侧可打开筛选浮层；多选与「全部」行为正确。
- 有筛选时图标有小圆点；清空后圆点消失。
- 无标签时无筛选图标。
- 日/周/月在相同筛选下任务集合一致（按主标签或附加标签命中）；切 tab 保留筛选状态。
- 月视图过滤后条与 overflow 计数基于过滤后的任务重算。
