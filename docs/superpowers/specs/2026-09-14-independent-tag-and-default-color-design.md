# 标签与默认色拆表（设置页 60×30 直角块）

- 状态：已确认（聊天设计评审 + 浏览器 demo）
- 日期：2026-09-14
- 范围：去掉「先建色卡再绑标签」；标签与默认色两张独立表；任务最多一个标签；设置页 60×30 直角色块；SQLite / 备份迁移。不改紧迫度曲线形状、不做云同步、不做色块拖拽排序、不改日/周/月几何。

## 1. 目标

用户在设置里分别管理**标签**和**默认色**。二者互不引用。时间条最多挂一个标签；颜色按覆盖 → 标签色 → 默认色 → 程序兜底解析。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 标签 | 自己的表：名字 + ARGB。身份是名字，同色不同名是两行 |
| 默认色 | 另一张表：只有 ARGB，没有名字。不指向任何标签 |
| 同色 | 数值可以碰巧相同，改/删一边不影响另一边 |
| 数量下限 | 两张表都可以空 |
| 时间条标签 | 0 或 1 个。去掉附加标签 / `task_tag` |
| 颜色覆盖 | 可选。任务上存 `override_argb`（色值拷贝，无外键） |
| 色块 UI | 一律 `60×30` 矩形，`border-radius: 0` |
| 选色 | 沿用现有系统取色器 + hex 联动 |
| 架构 | 拆掉共享 `color_swatch` 引用；schema 2 → 3 |

取代 `2026-08-10-editable-color-swatches-design.md` 中「任务/标签通过色卡 id 引用、至少 1 张、删默认须改绑」等约定。

## 3. 设置页

区块顺序：可视时段 → 紧迫窗口 → **标签** → **默认色** → 备份。不再出现「色卡」区块。

### 3.1 标签

竖排列表。每一行：

- 左：`60×30` 直角色块（1px 描边即可，无圆角、无胶囊按钮）
- 右：名字
- 再右：删除

| 操作 | 行为 |
| --- | --- |
| 点色块 | 展开/打开取色器，确认后只改这一行的 ARGB |
| 点名字 | 行内改名；空名不提交；与其它标签重名拒绝 |
| 新建 | 必须填名字 + 选色。颜色可与已有标签或默认色相同 |
| 删除 | 立刻删这一行。允许删光。无「最后一张不许删」 |

### 3.2 默认色

独立一栏，竖排（或紧凑竖排）`60×30` 直角块，无名字。

| 操作 | 行为 |
| --- | --- |
| 点色块 | 改这一块的 ARGB（不改任何标签）。色块只负责改色，不负责「选当前」 |
| 当前 | 表内 0 或 1 行 `is_current=1`，给无标签任务和主题用。当前那张用直角描边标出（只展示；点击仍是改色）。新建一行时新行成为当前；删当前且还有剩余 → 静默改到列表第一张；删光 → 走程序兜底。不弹「请先另选」 |
| 新建 | 只选色，追加一行并成为当前 |
| 删除 | 允许删光 |

## 4. 任务

### 4.1 一个标签

任务表单只选 **无** 或 **一个标签**（同一套 60×30 + 名字）。去掉「主标签 / 附加标签」。顶栏筛选只看这一个 id。

### 4.2 颜色覆盖（可选）

开关打开后，用 `60×30` 直角块选色。选项来自**当前标签色和默认色的色值快照**，点选后把 ARGB 写到任务上，**不**改任务的标签，**不**建立对任一张表的外键。两边列表都空时，直接打开取色器写入 ARGB。关掉开关则清除覆盖。

### 4.3 绘制解析

1. 任务有 `override_argb` → 用它  
2. 否则有标签 → 用该标签当前 ARGB（改标签色后，未覆盖的任务立刻变）  
3. 否则默认色表有当前行 → 用它  
4. 否则程序兜底：工厂霁蓝 `#457BD9`（与现网 `azure` 同色）

紧迫度仍从该色的 S/L 加深（HSL 由 ARGB 派生）。主题种子用「当前默认色」，没有则用同一兜底。

## 5. 删除与空表

| 动作 | 结果 |
| --- | --- |
| 删标签 | 该 `tag_id` 的任务改为无标签。覆盖色若有则仍在；否则走默认色 / 兜底。默认色表不动 |
| 删光标签 | 合法。筛选菜单只剩「全部」。已有覆盖色的任务外观不变 |
| 删默认色 | 标签表不动。无标签且无覆盖的任务改走剩余当前默认或兜底 |
| 删光默认色 | 合法。无标签且无覆盖 → 兜底色 |

## 6. 数据模型

### 6.1 表 `tag`

| 字段 | 说明 |
| --- | --- |
| `id` TEXT PK | UUID |
| `name` TEXT UNIQUE NOT NULL | 显示名，身份 |
| `argb` INTEGER NOT NULL | 不透明 ARGB |
| `sort_order` INTEGER NOT NULL | 创建序；本轮不拖拽 |

不再有 `swatch_id`。HSL 不存库，绘制时由 ARGB 计算。

### 6.2 表 `default_color`

| 字段 | 说明 |
| --- | --- |
| `id` TEXT PK | UUID |
| `argb` INTEGER NOT NULL | 不透明 ARGB |
| `is_current` INTEGER NOT NULL | 全局至多 1 行为 1；表空则全为 0 |
| `sort_order` INTEGER NOT NULL | 创建序 |

### 6.3 表 `task` 字段

| 原字段 | 新字段 |
| --- | --- |
| `primary_tag_id` | `tag_id` TEXT 可空（0 或 1 个标签） |
| `override_swatch_id` | `override_argb` INTEGER 可空 |
| `auto_swatch_id` | 删除（无标签颜色改查默认色表） |

删除表 `color_swatch`、`task_tag`。

## 7. 迁移

### 7.1 SQLite schema 2 → 3

1. 建 `default_color`。把旧 `color_swatch` 里 `is_default=1` 的那张 ARGB 插入一行并标当前。若旧表无默认，插入兜底霁蓝一行并标当前（迁移当下有默认；用户之后仍可删光）。
2. `tag`：为每个旧标签插入新行，`argb` = 当时 `swatch_id` 对应色卡的 ARGB。两个标签曾共用一张色卡 → 两行各自拷贝同一 ARGB，之后互不影响。
3. `task.tag_id` = 旧 `primary_tag_id`（该标签仍存在时）。`task_tag` 附加标签丢弃。
4. 旧 `override_swatch_id` → 查色卡 ARGB 写入 `override_argb`；无匹配则置空。
5. 删 `auto_swatch_id`、`override_swatch_id`、`primary_tag_id`、`color_swatch`、`task_tag`。

新库 `onCreate` 直接用 schema 3：空标签表；默认色表插入一张霁蓝当前色。不预置桃/芽绿等工厂色卡。

### 7.2 备份

- 格式版本升到 **3**：`tags[]` 含 `id/name/argb`；`default_colors[]` 含 `id/argb/is_current/sort_order`；任务用 `tag_id`、`override_argb`。
- 导入 v2：按 7.1 同样规则在导入时拆分（共用色卡拷贝成独立标签色；默认取旧默认色卡 ARGB）。
- 导入 v1：先按现网 v1→v2 色相规则，再走 v2→v3。

## 8. 边界

| 规则 | 行为 |
| --- | --- |
| 标签重名 | 拒绝保存 |
| 标签空名 | 拒绝保存 |
| 色块尺寸 | 设置页、任务表单、覆盖选色、默认色：全部 60×30、无圆角 |
| hex | 仍 `#RGB` / `#RRGGBB`；非法不写入 |
| slate / 工厂色卡名 | 不再作为用户可见实体；仅兜底 ARGB 保留霁蓝 |
| 筛选 | 命中 `task.tag_id`；空筛选 = 全部 |

## 9. 非目标

- 附加标签
- 标签与默认色互相改绑 / 共享 id
- 色块圆角或圆形
- 色块拖拽排序
- 改紧迫度插值曲线
- 深色主题壳层
- 云同步

## 10. 与既有规格关系

- 取代 `docs/superpowers/specs/2026-08-10-editable-color-swatches-design.md` 的绑定模型与「至少 1 张 / 删除改绑」。
- 顶栏标签筛选仍有效，但只匹配唯一 `tag_id`（不再并附加标签）。
- 设置抽屉、内联取色器、紧迫度曲线形状保持；取色器挂到 60×30 色块上，不再挂圆形色点。
