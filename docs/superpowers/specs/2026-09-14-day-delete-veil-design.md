# 日视图双击删除层（红绿半屏）

- 状态：已确认（聊天设计评审）
- 日期：2026-09-14
- 范围：仅日视图。双击时间条出半透明红绿全屏层；单击仍开任务表单。不改周/月、不改右键实际时间、不改空白长按创建。

## 1. 目标

双击一条日视图时间条并松开后，立刻盖一层半透明全屏遮罩，底下甘特图仍能看见。点红半屏删除该条；点绿半屏或 Esc 关掉遮罩，任务还在。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 打开 | **同一条**上双击，第二次抬手立刻出层（不再额外等 250ms） |
| 单击 | 仍打开任务表单。为区分双击，大约晚 300ms（Flutter 双击窗口） |
| 拖条 | 按下后位移超过 `kTouchSlop` 才开始移动/缩放；取消待定单击和双击 |
| 按住未抬手 | 不出层 |
| 长按空白 | 约 350ms 再拖 → 创建（现状） |
| 右键色条 | 设实际时间（现状），不出层 |
| 层位置 | 日视图**根 Stack**，盖在 Canvas / 横向 Scroll 上面。不放 AppShell、不用 Dialog/Overlay |
| 上半屏 | `0x73FF8A80`，任意处删除该任务并关层 |
| 下半屏 | `0x7381C784`，任意处只关层 |
| 返回 | Esc ≡ 绿区 |
| 层打开时 | Scroll 与 Canvas `IgnorePointer`（等价 HitTestMode.None），不能横滑、点不到条 |
| alpha | 必须 `0x73`。禁止 `0xFF` 实心红绿把甘特图盖死 |

## 3. 交互

1. 第一次在色条上按下并松开、且未超过 slop：进入双击等待（约 300ms）。超时未出现第二次点击 → 打开该任务表单。
2. 等待窗口内在**同一条**上再次按下并松开、且两次都未超过 slop：立刻出红绿层，**不**打开表单。
3. 两次点击落在不同条上：不算双击；按单击规则处理第二次所点的条。
4. 任一次按下后移动超过 slop：取消待定单击/双击，按现网拖动/缩放。
5. 层打开期间：底层不接收指针；点红 → `tasks.delete(id)` 后关层；点绿或 Esc → 只关层。
6. 层打开时再双击无效（点被层吃掉）。删除后或取消后恢复甘特手势。

## 4. 遮罩 UI

- 全屏 `Column`：两个 `Expanded` 子项，各 50% 高度。
- 上：`Color(0x73FF8A80)`；下：`Color(0x7381C784)`。
- 热区是整半屏，不是文字。本轮不强制加「删除 / 取消」文案。
- 必须挂在 `DayGanttPage` 根 `Stack` 上，与现网侧栏抽屉同级思路：和页面同级、盖在 Canvas 上面。

## 5. 手势拆分（对齐 HarmonyOS TapClassifier）

现网 `DayGanttGestures` 在色条 `pointerDown` 时立刻 `_beginBarDrag`，双击会被当成两次微移。改为：

- 色条 down：只记录目标，**不**进 move/resize，也**不**锁滚动。
- move 超过 slop：再 `_beginBarDrag`，并取消待定 tap / double-tap。
- up 且从未超过 slop：交给单击/双击判定。
- 空白处长按 350ms 创建逻辑不变。
- 打开层时：手势层与横向 `ScrollView` 均忽略命中；不要用自绘组件去「挡」Canvas。

## 6. 实现落点

- `lib/ui/day/delete_veil.dart`（或同等）：两半屏颜色与点击回调；颜色常量写死为上面两个 ARGB。
- `lib/ui/day/day_gantt_page.dart`：根 Stack 放层；`deleteVeilTaskId`；Esc；删除走已有 `tasks.delete`。
- `lib/ui/day/day_gantt_gestures.dart`：slop 后再拖条；单击延迟；双击回调 `onDoubleTapTask`。
- 测试：层颜色与 50% 高度；双击出层、单击仍回调表单；层开时点不到底下；红删绿关；Esc 关。

- 恢复旧的双击删除对话框
- 把「设实际时间」从右键改成长按

## 8. 验收

- 双击同一条，第二次松开立刻看到半透明红上绿下，底下条仍隐约可见。
- 单击仍打开表单（允许约 300ms 延迟）。
- 点红：该任务消失；点绿或 Esc：任务仍在、层关掉。
- 层开着不能拖时间轴、不能点到底下的条。
- 拖条、空白创建、右键实际时间与现网一致。
