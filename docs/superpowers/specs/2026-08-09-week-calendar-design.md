# 周视图：日期列 × 时刻行

- 状态：已实现（方案 A；跨日按日裁切；周起周一；重叠并排分栏）
- 日期：2026-08-09

## 1. 目标

周视图改为经典周历坐标，不再使用「横向连续 7 天甘特」：

| 轴 | 含义 |
| --- | --- |
| 横 | 周一 → 周日（日期维度） |
| 纵 | 当日 0:00 → 24:00（时刻维度） |

## 2. 任务放置

- 用现有 `DaySegmenter` 按自然日切开；跨日/跨夜任务在每一天各有一段。
- **无**顶部全天/跨日横条区。
- 块几何：列 = 该日；`top/height` = 段在当日的起止分钟 / 1440。

## 3. 重叠：并排分栏

同一天内，时间半开区间有交集的任务组成重叠簇；簇内按开始时间排序，分配 `columnIndex / columnCount`，均分列宽。

```
        周三
   ┌─────┬─────┐
9  │拍摄  │     │
   │     │面试  │  ← 重叠段左右并排
12 │     │     │
   ├─────┴─────┤
13 │   剪辑     │  ← 无重叠，接近满宽
14 └───────────┘
```

不采用上下错层叠盖。

## 4. 视觉与交互

- 块内：加粗标题 + 时间元信息（可与日视图单行风格一致）；过矮则只显示标题。
- 颜色：色板 + `UrgencyPalette`。
- 点击块 → 任务表单；本版可延后拖拽改时/空白拖建（优先可读布局）。
- 纵滚默认滚到设置的可视时段起点；今天列日期高亮；可选「现在」横线。
