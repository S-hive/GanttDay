# 日视图任务条字幕完整溢出

- 状态：已确认
- 日期：2026-08-09

## 行为

日视图每条任务始终绘制一行完整文案：

`任务名  开始 – 结束（时长）`

（时间格式沿用 `formatBarTimeLabel`；有备注时接在后面。）

- 不得因色条过窄而省略起止或时长
- 不得对名称 / 起止 / 时长使用条内省略号截断
- 文字从 sticky 左原点向右绘制，允许超出色条右边界（可叠在右侧空白或其他条上）
- 备注与三项同一策略：完整溢出，不截断
- 命中与拖拽区域仍以色条矩形为准，不因文字变宽而扩大
