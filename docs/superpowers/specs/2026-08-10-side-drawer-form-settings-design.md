# 任务编辑 / 设置：右侧模糊抽屉

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：点时间条打开的任务编辑、点设置打开的设置页 → 右侧滑入抽屉 + 背景模糊；不改拖拽新建「新任务」小弹层；设置页嵌套确认/色卡对话框仍用现有 Dialog

## 1. 目标

用图示风格的右侧抽屉替代全页 `Navigator.push`，主界面留在背后并模糊；减少上下文切换感。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 入口 | 任务编辑（点日视图时间条）、设置（AppBar 齿轮） |
| 呈现 | `showGeneralDialog`（或等价）+ 右侧滑入面板 |
| 宽度 | 约屏宽 40%，clamp 约 360–480 |
| 背景 | `BackdropFilter` 模糊 + 半透明遮罩 |
| 任务关闭 | 点模糊 / 系统返回 = **保存成功后关闭**（校验失败则留在抽屉）；无单独「保存」按钮 |
| 设置关闭 | 设置仍**即时写入**；点模糊 / 系统返回 = 关闭；无单独「完成」按钮 |
| 非目标 | 拖拽新建弹层、周/月若另有编辑入口本轮可不改（若与 shell 共用 `_openForm` 则一并受益） |

## 3. 交互

1. 打开：面板自右滑入，左侧圆角；背后甘特/导航模糊。
2. 点模糊区：关闭抽屉。**任务编辑会先保存**（失败则提示并留在抽屉）；设置已即时保存则直接关。
3. 任务无单独「保存」按钮；删除 / 标记完成等操作仍保留并在成功后关闭。
4. 设置无单独「完成」按钮。
5. 设置内色卡/标签/导入导出确认：仍为居中 Dialog，叠在抽屉之上；关 Dialog 不关抽屉。

## 4. 实现落点

- 新建：`lib/ui/common/side_drawer.dart`（`showSideDrawer` + 模糊遮罩 + 右侧 `SlideTransition` 壳）。
- 修改：`lib/ui/shell/app_shell.dart` — `_openForm` / `_openSettings` 改调抽屉而非全页 route。
- 修改：`TaskFormPage` / `SettingsPage` — 适配抽屉内容（去掉依赖全屏 push 的 AppBar 返回；任务保留「保存」，设置增加「完成」或等价页脚）。

## 5. 验收

- 点时间条 / 设置均从右侧打开抽屉，背景模糊。
- 任务：点模糊 = 保存并关闭；校验失败留在抽屉并提示。
- 任务无「保存」按钮；删除 / 完成等仍可用。
- 设置改项仍即时生效；点模糊关闭；无「完成」按钮。
- 设置内嵌套 Dialog 行为与现网一致。
