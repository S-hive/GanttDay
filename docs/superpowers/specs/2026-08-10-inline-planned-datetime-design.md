# 计划时间：行内展开数字框

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：任务抽屉「计划开始 / 计划结束」选时交互；不改完成对话框实际时间轴、不改甘特拖拽几何

## 1. 目标

取消 `showDatePicker` / `showTimePicker` 弹窗；点计划时间行后**向下展开**，用**预填数字框**改年/月/日/时/分；再点同一行即写入并收起。无「确定」按钮。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 呈现 | 行内手风琴，展开在对应 ListTile 下方 |
| 字段 | 年、月、日、时、分（预填当前值，可改数字） |
| 分钟 | 收起时对齐到最近 15 分钟（与现网一致） |
| 确认 | 展开条右侧「确定」提交并收起；再点同行也可提交 |
| 同时展开 | 至多一行；切到另一行时先提交当前草稿 |
| 非法日期 | 不收起，展开区下短错误文案；不弹 Dialog |

## 3. 交互

| 操作 | 行为 |
| --- | --- |
| 点收起的「计划开始」或「计划结束」 | 展开该行编辑器，五个框填入当前 `_start` / `_end` |
| 点已展开的同一行 | 解析 → 15 分对齐 → 更新对应 DateTime → 收起；摘要字幕刷新 |
| 点另一行 | 先对当前展开行执行「提交并收起」；成功后再展开另一行。若提交失败则留在当前展开 |
| 抽屉关闭（模糊 / 返回） | 若仍有展开行，先尝试提交该草稿；再走现有保存关抽屉逻辑 |
| 输入 | 仅数字；框宽适配位数（年 4、其余 2） |

展开区布局示意（单行或可换行）：

`[年____] [月__] [日__]   [时__] : [分__]`

可选轻量标签「年/月/日」「时」「分」，不抢视觉。

## 4. 校验

- 组成 `DateTime` 失败（如 2 月 30 日）→ 提示「日期无效」，保持展开。
- 提交成功后，结束须仍满足现有「结束 > 开始」规则：若违反，可写入时间但仍由表单底部 `_error` 在最终保存时拦住（与现网一致）；或在收起时即时设 `_error`（实现任选，优先与现有 `_save` 校验复用）。
- 分钟对齐：`(m + 7) ~/ 15 * 15`，与现 `_pickDateTime` 相同。

## 5. 实现要点（约束）

- 去掉 `task_form_page.dart` 中对 `showDatePicker` / `showTimePicker` 的调用。
- 状态：`enum { none, start, end }` + 五个 `TextEditingController`（或等价），展开时从当前 DateTime 灌入。
- 可抽小组件（如 `InlineDateTimeEditor`）便于单测解析/对齐；非必须。

## 6. 非目标

- 完成对话框的实际时间拖拽轴
- 系统日历 / 时钟 UI
- 秒级精度、时区选择

## 7. 验收

- 点计划开始/结束无 Date/Time picker 弹窗
- 展开见预填年/月/日/时/分
- 再点同行或点「确定」：摘要更新、展开收起、分钟为 0/15/30/45
- 非法日期不收起并有文案
- 展开条右侧有「确定」按钮
