# 日视图任务条标题优先显示

- 状态：已实现
- 日期：2026-08-08
- 范围：日视图甘特条 caption（`DayGanttPainter._paintBarCaption`）

## 1. 问题

日视图任务条在高度/宽度不足以同时放下「标题 + 时间」两行时，当前逻辑回退为**只画时间**，并用省略号裁切（例如 `23:15…`）。用户希望此时优先看到**完整任务名**。

## 2. 目标

| 场景 | 行为 |
| --- | --- |
| 条内空间足够叠两行 | 保持现状：第 1 行标题，第 2 行时间（及可选备注）；条内裁切 |
| 空间不足以叠两行 | **只显示任务名**；不加省略号；**允许画出条外**（不按条宽 clip） |
| 周/月视图 | 不改动 |

## 3. 行为细节

1. **触发条件**：沿用现有 `canStack == false`（高度不够放下标题+时间块，或可用宽度过窄等现有判定）。
2. **窄条内容**：仅任务名；不画时间、不画备注。
3. **完整显示**：单行、无 `ellipsis`；布局时给标题足够 `maxWidth`（与跨夜短条类似的下限，例如 280），且绘制时不对条矩形做 clip。
4. **粘性 X**：仍使用现有 `stickyCaptionLeft`，避免横向滚动时标题立刻消失。
5. **极长标题**：允许横向溢出覆盖相邻区域；本版不换行、不抬高行高。

## 4. 非目标

- 不改变任务创建/编辑交互
- 不改变跨夜 stub 的 `overflowCaption` 语义（可与窄条标题溢出共用绘制路径，但不必改 `PlacedBar` 字段含义）
- 不做周视图同步改动

## 5. 实现落点

- 主要改动：`lib/ui/day/day_gantt_painter.dart` 中 `_paintBarCaption` 的 `!canStack` 分支（由「only time + ellipsis + clip」改为「full title + no ellipsis + no bar clip」）
- 可选：抽一小段与 `overflowCaption` 共用的「允许溢出的标题绘制」逻辑，避免重复；以可读性为准，不强行重构

## 6. 验收

- 短/矮任务条：可见完整任务名，不再出现被截断的时间串作为唯一 caption
- 足够高的任务条：仍显示标题 + 时间两行
- 横向滚动时，窄条溢出标题仍遵循粘性起点逻辑
