# 日视图内设置实际时间（不弹窗）

- 状态：已确认（聊天：右键不弹窗，页内设实际时间）
- 日期：2026-08-10
- 范围：日视图右键时间条；取代完成弹窗主路径

## 行为

- 右键任务条 → **不弹窗**，进入「设置实际时间」模式。
- 其它任务条隐藏；仅保留该任务的**计划参考条**（色卡颜色，固定）及已有实际条（若有）。
- 设置实际时间：与日视图**建条相同**——空白处长按拖拽（`proposeCreate`），松手写入 `complete` 并退出模式。
- 已有实际条：右键该实际条 → `uncomplete` 并退出。
- Esc / 右键空白 / 顶栏「退出」→ 退出模式不改数据（未松手完成前）。
