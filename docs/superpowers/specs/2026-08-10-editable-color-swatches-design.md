# 可编辑色卡（设置页完整管理）

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：色卡 CRUD、按 id 绑定任务/标签、设置页选色（系统取色器 + hex）、DB/备份迁移；不改紧迫度曲线形状、不做云同步、不做色卡拖拽排序

## 1. 目标

用户可在设置页**完整管理色卡**（增删、改名、改色、指定默认）。任务与标签通过**色卡 id**引用颜色；改色卡颜色后所有引用立刻更新。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 管理范围 | 完整管理（增删改名改色） |
| 绑定方式 | 色卡 id（非裸色相） |
| 选色方式 | 系统取色器 + `#RRGGBB` / `#RGB` 输入，二者联动 |
| 数量下限 | 至少 1 张 |
| 默认/兜底 | 色卡列表星标「设为默认」；新建任务无覆盖/无主标签时用默认卡；兜底即可改 |
| 架构 | 独立表 `color_swatch`（方案 1） |

## 3. 设置页交互

在设置页增加 **「色卡」** 区块（交互对齐现有标签列表）：

| 操作 | 行为 |
| --- | --- |
| 列表 | 每行：色块预览 · 名称 · 默认星标 · 编辑 · 删除 |
| 新建 | 对话框：名称 + 色块（点开系统取色器）+ hex 输入；保存后追加 |
| 编辑 | 同新建表单；改名/改色写回该色卡 id |
| 设为默认 | 点星标；全局仅一张默认 |
| 删除 | 仅剩 1 张时禁用。若仍有任务/标签引用：对话框选 **改绑到另一张** 或 **改绑到当前默认**，确认后删除 |

选色：系统取色器与 hex 联动；非法 hex 不写入，预览回退到上次合法色。

## 4. 数据模型

### 4.1 表 `color_swatch`

| 字段 | 说明 |
| --- | --- |
| `id` TEXT PK | 稳定 id（工厂色沿用 `azure` / `peach` / …；用户新建用 UUID） |
| `name` TEXT | 显示名 |
| `argb` INTEGER | 不透明 ARGB（权威颜色；HSL 由它派生供紧迫度使用） |
| `is_default` INTEGER | 全局恰好 1 张为 1 |
| `sort_order` INTEGER | 列表顺序（按创建序即可；本轮不做拖拽） |
| `slate` INTEGER | 现有「灰」迁移时保留；中性语义与现网一致 |

### 4.2 引用字段替换

| 原字段 | 新字段 |
| --- | --- |
| `task.auto_hue` | `task.auto_swatch_id`（NOT NULL） |
| `task.override_hue` | `task.override_swatch_id`（可空） |
| `tag.hue` | `tag.swatch_id`（NOT NULL） |

绘制解析顺序：`override_swatch_id` → 主标签 `swatch_id` → `auto_swatch_id` → 查色卡得 `argb` / HSL；紧迫度仍从该色 S/L 加深。

## 5. 迁移

### 5.1 SQLite schema 1 → 2

1. 创建 `color_swatch`，插入当前 8 张工厂色；`azure` 为默认。
2. 任务/标签：色相精确匹配工厂色 → 绑对应 id；否则新建用户色卡（名称如「自定义色」）再绑定，不丢颜色。
3. 删除旧 hue 列。

### 5.2 备份

- 备份格式版本升到 **2**：含 `color_swatches`；任务/标签使用 swatch id。
- 导入 v1：按同样 hue→色卡规则在导入时迁移。

## 6. 别处选色与创建默认

- `HuePicker`（或后继组件）展示**当前色卡列表**，点选写入 swatch id；去掉自定义色相滑条。
- 自定义颜色只通过设置页「新建色卡」进入色板，再被任务/标签选用。
- 新建任务：`auto_swatch_id` = 当前默认色卡（不再随机 `pickAutoHue`）。
- 新建标签：默认建议仍为「距已有标签色最远」的色卡（按色相距离），可改选。

## 7. 边界规则

| 规则 | 行为 |
| --- | --- |
| 至少 1 张 | 最后一张禁止删除 |
| 删默认卡 | 须先另设默认，或在删除流程中指定继任默认 |
| 删仍被引用的卡 | 强制改绑；禁止悬空 id |
| 改色 | id 不变 → 所有引用立刻变色 |
| 改名 | 只影响显示 |
| hex | `#RGB` / `#RRGGBB`，大小写均可；非法不提交 |
| 紧迫度 | 不改曲线形状；从色卡当前 S/L 加深 |
| slate | 灰卡迁移保留；特殊处理与现网一致 |

## 8. 非目标

- 色卡拖拽排序
- 云同步
- 改紧迫度插值曲线
- 深色主题壳层

## 9. 与既有规格关系

取代 `2026-08-08-color-palette-design.md` 中「存储仍为整数 hue / 固定 8 色常量 / 随机 autoHue / 自定义色相滑条」等约定；工厂 8 色仍作为**首次迁移种子**，之后以用户库内色卡为准。
