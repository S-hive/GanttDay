# 色卡：取消长按菜单，删除移入取色器底栏

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：设置抽屉内联色卡取色器；不改色卡数据模型、删除确认/改绑逻辑、标签区、他处弹窗取色（除非共享面板 API 扩展）

## 1. 目标

去掉色卡长按底部菜单；在内联取色器底部**左侧**增加「删除」，与右侧「取消 / 确定」相对。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 长按弹窗 | 取消（无 `showModalBottomSheet` 色卡动作菜单） |
| 长按手势 | 去掉；色卡仅点击展开/收起编辑 |
| 删除入口 | 取色器底栏左侧「删除」 |
| 新建模式 | 不显示删除 |
| 仅 1 张色卡 | 不显示删除（与现网 `canDelete` 一致） |
| 设为默认 | 本轮去掉入口；默认仍可用红描边标识 |
| 删除确认 | 沿用现有 `_deleteSwatch` 对话框（含默认色卡改绑） |

## 3. 交互

| 操作 | 行为 |
| --- | --- |
| 点色卡 | 展开内联取色器（与现网一致） |
| 编辑态底栏 | 左「删除」；右「取消」「确定」（`canDelete` 为真时） |
| 点删除 | 走现有删除确认；成功后收起面板并刷新列表 |
| 新建展开 | 底栏仅「取消」「确定」，无删除 |
| 长按色卡 | 无动作（不再弹出菜单） |

Tooltip：改为「点击改色」；默认色卡可用「默认色卡」之类，不再提长按。

## 4. 实现落点

- 修改：`lib/ui/common/argb_color_field.dart` — `ArgbColorPickerPanel` 增加可选 `VoidCallback? onDelete`；非空时底栏 `Row`：左删除、`Spacer`、取消、确定。对话框包装不传 `onDelete`（行为不变）。
- 修改：`lib/ui/settings/swatch_inline_host.dart` — 去掉 `_SwatchChip` 长按与 bottom sheet；编辑且 `canDelete` 时把 `onDelete` 传给面板；新建不传。
- 测试：更新 `test/ui/settings_swatch_inline_picker_test.dart`（及面板相关测试若有）：断言无长按菜单；编辑态可见删除；新建态不可见删除。

## 5. 非目标

- 新的「设为默认」入口
- 改删除确认文案或改绑规则
- 任务表单等其他选色 UI

## 6. 验收

- 长按色卡不再出现「设为默认 / 删除 / 取消」菜单
- 编辑色卡时取色器左下有「删除」；点后仍走确认对话框
- 新建时无「删除」
- 仅剩一张色卡时编辑展开也无「删除」
- 取消 / 确定行为与现网一致
