# 底栏视图切换：三等分大点击区

- 状态：已确认（聊天设计评审）
- 日期：2026-08-10
- 范围：AppShell 底部日/周/月导航；只扩点击区与选中视觉，不改切视图逻辑

## 1. 目标

把底栏分成三等分，整段可点切换日/周/月视图；只保留图标、无文字；选中几乎无背景高亮，主要靠图标颜色区分。

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 布局 | 自定义 `Row` + 三个等宽分区（各约 1/3） |
| 内容 | 仅图标（日 / 周 / 月），无 label 文案 |
| 命中区 | 每等分整宽整高可点 |
| 选中视觉 | 方案 C：无 indicator / 无等分背景块；选中图标用主题色（或 `onSurface`），未选中半透明灰 |
| 高度 | 保持约 56 |
| 非目标 | 不改 `_navIndex` → 日/周/月 body 映射；不加文字标签 |

## 3. 交互

1. 点左等分 → `_navIndex = 0`（日视图）。
2. 点中等分 → `_navIndex = 1`（周视图）。
3. 点右等分 → `_navIndex = 2`（月视图）。
4. 图标沿用现有：`view_day_outlined` / `view_week_outlined` / `calendar_month_outlined`。

## 4. 实现落点

- 修改：`lib/ui/shell/app_shell.dart` — 用自定义三等分底栏替换 `NavigationBar`（可同文件小组件或内联 `Row`）。
- 可选：极简 widget 测试（三等分点击切换 index）；无现成 shell 测试则可不强制。

## 5. 验收

- 底栏视觉上三等分；点左/中/右三分之一任意位置均可切到对应视图。
- 无文字；选中无 Material indicator、无整段背景高亮。
- 选中/未选中主要靠图标颜色区分。
- 日/周/月页面切换行为与现网一致。
