# GanttDay v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Windows-only Flutter app where freelancers can create, drag, and complete personal Gantt tasks with local SQLite storage, urgency coloring, and planned-vs-actual overlay.

**Architecture:** Pure-Dart domain modules own geometry, midnight splits, lane packing, urgency colors, and complete-dialog axis zoom. UI talks only to domain + three platform interfaces (`TaskRepository`, `SettingsStore`, `FileGateway`). v1 implements those with SQLite + Windows file dialogs.

**Tech Stack:** Flutter (stable, Windows desktop), Dart 3, `sqflite_common_ffi` + `sqlite3_flutter_libs`, `path_provider`, `file_picker`, `uuid`, `flutter_test` / `test`.

**Spec:** `docs/superpowers/specs/2026-08-08-ganttday-design.md`

## Global Constraints

- Platform v1: Windows only (exe/msix later); no Android/HarmonyOS package in this plan
- Time storage: local wall-clock minutes since 1970-01-01 00:00, no timezone conversion
- Snap: round to nearest 15 minutes; min duration 15 minutes
- Overlap: different tasks get separate lanes; abutting ends (12:00/12:00) do **not** overlap
- Same task planned+actual: stack in one lane (thick gray planned, thin vivid actual)
- Urgency: linear within configurable window (default 7 days); overdue = max vivid + hatch, bar stays at planned span
- Complete dialog: axis zoom-out+pan only when selection would leave viewport; shrink-only while dragging; recompute on pointer-up
- DB open failure: never silently recreate empty DB
- Import: all-or-nothing transaction; duplicate ids skip+report
- Domain packages: zero Flutter imports under `lib/domain/`
- Commits: small, after each task’s green tests

```dart
// lib/domain/time/wall_clock.dart
typedef WallMinutes = int;

class WallClock {
  static WallMinutes minutes(DateTime local) {
    final l = DateTime(local.year, local.month, local.day, local.hour, local.minute);
    return l.millisecondsSinceEpoch ~/ 60000;
  }

  static DateTime dateTime(WallMinutes m) {
    final utcish = DateTime.fromMillisecondsSinceEpoch(m * 60000, isUtc: false);
    return DateTime(utcish.year, utcish.month, utcish.day, utcish.hour, utcish.minute);
  }

  static WallMinutes dayStart(WallMinutes any) {
    final d = dateTime(any);
    return minutes(DateTime(d.year, d.month, d.day));
  }

  static WallMinutes dayEndExclusive(WallMinutes any) => dayStart(any) + 24 * 60;
}
```

```dart
// lib/domain/gantt/gantt_geometry.dart
import '../time/wall_clock.dart';

class GanttGeometry {
  static const minDurationMinutes = 15;

  GanttGeometry({
    required this.viewStart,
    required this.viewEnd,
    required this.widthPx,
  }) : assert(viewEnd > viewStart),
       assert(widthPx > 0);

  final WallMinutes viewStart;
  final WallMinutes viewEnd;
  final double widthPx;

  double get _span => (viewEnd - viewStart).toDouble();

  double xOf(WallMinutes t) => (t - viewStart) / _span * widthPx;

  WallMinutes timeOf(double x) =>
      viewStart + ((x / widthPx) * _span).round();

  WallMinutes snap(WallMinutes t) {
    final r = t % 15;
    if (r < 8) return t - r;
    return t + (15 - r);
  }

  WallMinutes clampDuration({
    required WallMinutes start,
    required WallMinutes end,
  }) {
    if (end < start + minDurationMinutes) return start + minDurationMinutes;
    return end;
  }
}
```

```dart
class DaySegmenter {
  static List<GanttSegment> segmentsForDay(Task task, WallMinutes dayAny) {
    final day0 = WallClock.dayStart(dayAny);
    final day1 = WallClock.dayEndExclusive(dayAny);
    final start = task.plannedStart;
    final end = task.plannedEnd;
    if (start >= day1 || end <= day0) return const [];
    final clippedStart = start < day0 ? day0 : start;
    final clippedEnd = end > day1 ? day1 : end;
    if (clippedEnd <= clippedStart) return const [];
    return [GanttSegment(taskId: task.id, start: clippedStart, end: clippedEnd)];
  }
}
```

- [ ] **Step 3: Implement greedy earliest-lane packing**

```dart
class LaneLayout {
  static String keyOf(GanttSegment s) => '${s.taskId}:${s.start}';

  static Map<String, int> assign(List<GanttSegment> segs) {
    final sorted = [...segs]..sort((a, b) {
      final c = a.start.compareTo(b.start);
      return c != 0 ? c : a.end.compareTo(b.end);
    });
    final laneEnds = <int>[]; // exclusive end per lane
    final out = <String, int>{};
    for (final s in sorted) {
      var lane = 0;
      while (lane < laneEnds.length && laneEnds[lane] > s.start) {
        lane++;
      }
      if (lane == laneEnds.length) {
        laneEnds.add(s.end);
      } else {
        laneEnds[lane] = s.end;
      }
      out[keyOf(s)] = lane;
    }
    return out;
  }
}
```

```dart
class UrgencyPalette {
  static TaskPaint paint({
    required int baseHue,
    required WallMinutes plannedStart,
    required WallMinutes plannedEnd,
    required WallMinutes now,
    required bool isDone,
    WallMinutes? actualStart,
    WallMinutes? actualEnd,
    required int urgencyWindowDays,
  }) {
    if (isDone) {
      return TaskPaint(
        planned: BarPaint(hue: baseHue, saturation: 0.12, lightness: 0.55, hatchOverdue: false, isPlannedGray: true),
        actual: BarPaint(hue: baseHue, saturation: 0.85, lightness: 0.50, hatchOverdue: false, isPlannedGray: false),
      );
    }
    final windowMin = urgencyWindowDays * 24 * 60;
    final remaining = plannedEnd - now;
    final overdue = remaining < 0;
    double t; // 0 calm .. 1 urgent
    if (remaining >= windowMin) {
      t = 0;
    } else if (overdue) {
      t = 1;
    } else {
      t = 1 - (remaining / windowMin);
    }
    final sat = 0.25 + 0.75 * t;
    final light = 0.72 - 0.27 * t;
    return TaskPaint(
      planned: BarPaint(
        hue: baseHue,
        saturation: sat,
        lightness: light,
        hatchOverdue: overdue,
        isPlannedGray: false,
      ),
    );
  }
}
```
